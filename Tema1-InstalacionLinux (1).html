💻 Repaso: Virtualización e instalación

Práctica 01 · Administración Linux · Preguntas de tus tests explicadas en sencillo

1. Instalar Linux sin perder Windows

  • Arranque dual: se particiona el disco y se elige un sistema al arrancar; para cambiar hay que reiniciar.
  • Virtualización: se instala un software de máquina virtual y los sistemas corren a la vez (la VM es un proceso más).

2. Hipervisor y terminología

  • Tipo 1 (nativo, bare metal): corre directamente sobre el hardware (ej.: Hyper-V). Tipo 2 (hosted): corre sobre un SO anfitrión. VirtualBox es de tipo 2.
  • Anfitrión / host: SO real. Máquina virtual (VM): entorno que crea el hipervisor. Invitado / guest: SO que corre dentro. Guest additions: controladores del invitado.
  • Ventajas: varios SO a la vez, instalación sencilla (copiar archivos), pruebas sin riesgo. Inconveniente: más lento por la sobrecarga. El tipo 1 es más eficiente que el tipo 2 (sin SO anfitrión de por medio).

3. Crear la máquina virtual

  1. Nombre y SO (y la ISO). 2. Instalación desatendida (opcional). 3. Hardware: RAM y CPUs. 4. Disco duro: nuevo, existente o ninguno.
  • Ubuntu 24.04 pide: CPU de 2 GHz y 2 núcleos, 4 GB de RAM y 25 GB de disco.
  • La RAM de la VM se resta a la del anfitrión. Guía: total − lo que necesita el anfitrión; o 60%/40% con mínimo 384 MB.
  • Discos: VDI (propio), VHD, VMDK, HDD, QCOW, QED. Dinámico = crece hasta el máximo (más lento, ahorra espacio); reservado = todo de golpe.
  • Archivos: .vbox (configuración), .vbox-prev (copia), .vdi (disco), en VirtualBox VMs.

4. Instantáneas

Guardan el estado para volver atrás: configuración (XML), estado de los discos virtuales y estado de la memoria (solo si estaba en ejecución). Se exportan con la VM.

5. Fuentes de instalación

FuenteIdea

Por redpequeño instalador y descarga el resto

Una ISO es una copia exacta, sin comprimir, de un CD/DVD. Se usa mejor que el CD físico porque es más rápida.

6. Particiones

  • MBR: discos hasta 2 TB, máx. 4 primarias. GPT: solo con UEFI, discos mayores y casi sin límite.
  • Primaria: máx. 4 (o 3 + 1 extendida); un disco formateado entero es una primaria. Extendida: una por disco, contiene lógicas, sin sistema de archivos propio. Lógica: se formatea (FAT32, NTFS, ext4); máx. 23 en la extendida.
  • Formato (sistema de archivos) ≠ tipo de partición.
  • Esquema Linux: /, /home y swap (≥ doble de la RAM; hoy suele ser un archivo de intercambio). /boot para el arranque. La swap ya no «aumenta la eficiencia»: hoy sirve sobre todo para hibernar/suspender (además de guardar procesos parados); no es obligatoria.
  • GRUB es el gestor de arranque (/boot/grub/grub.cfg). En sistemas duales conviene instalar Linux después de Windows.

7. Guest additions

  • Dan: ratón integrado, mejor vídeo, hora sincronizada, carpetas compartidas, ventanas sin costuras, portapapeles compartido y entrada automática.
  • Instalación: Dispositivos → Insertar imagen de CD de los complementos → sudo apt install bzip2 → sudo ./VBoxLinuxAdditions.run → reiniciar.
  • Mientras no están instaladas, el ratón se libera con la tecla host (Ctrl derecho).

8. Compartir máquinas

OVF: varios archivos. OVA: un solo archivo (variante de tar), preferible. Menú Archivo → Exportar / Importar servicio virtualizado.

9. Distribuciones y núcleo

  • Distro = núcleo Linux + herramientas GNU + X Window + otro software. Matrices: Debian, openSUSE, Arch, Gentoo, Fedora/Red Hat.
  • Ubuntu: versión cada 6 meses (año.mes; 24.04 = abril de 2024, Noble Numbat); LTS = 5 años de soporte.
  • Núcleo X.Y.Z (principal, secundaria, revisión). uname -s nombre, -r versión, -m arquitectura, -a todo.

11. Windows y certificaciones

Hyper-V es el hipervisor de tipo 1 de Windows; WSL ejecuta Linux sobre él (wsl --list, --install, --shutdown). LPI ofrece Linux Essentials y LPIC-1/2/3.
