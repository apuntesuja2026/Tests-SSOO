👥 Repaso: Gestionando usuarios

Práctica 06 · Administración Linux · Preguntas de tus tests explicadas en sencillo

1. Usuarios, root y nombres

  • Linux es multiusuario: hay root (administrador, UID 0; úsalo solo cuando haga falta) y usuarios normales.
  • Nombre de usuario: único, con letras, números, _ y .; sin espacios; hasta 32 caracteres; distingue mayúsculas; mejor empezar por letra y en minúsculas. Recomendación de los tests: solo letras y números y máximo 8 caracteres.

2. Grupos

  • Los grupos no son cuentas: organizan cuentas para dar permisos a varios a la vez (más seguridad).
  • Grupo primario (uno solo, el GID de /etc/passwd): es el grupo de los archivos que creas. En Ubuntu se crea uno con tu nombre. Grupos secundarios: los demás.
  • Sin grupo primario no hay login. newgrp g cambia temporalmente el primario (hasta exit). Si el grupo tiene contraseña, los no miembros deben teclearla.

3. UID y GID

NúmeroQué es
0root
1–999 (Ubuntu)cuentas de sistema (daemon, www-data…): sin contraseña, shell nologin o /bin/false
1000+usuarios normales (UID_MIN/GID_MIN en /etc/login.defs)

Linux trabaja con los números, no con los nombres. Si borras un usuario sin borrar sus archivos y se reutiliza su UID, el nuevo usuario hereda esos archivos. id muestra UID, GID y grupos.

4. Ficheros importantes

FicheroContenido
/etc/passwd7 campos: nombre:x:UID:GID:GECOS:home:shell (la x = contraseña en shadow)
/etc/shadow9 campos, solo root: nombre, contraseña cifrada (! = bloqueada, * = cuenta de sistema), último cambio, mín., máx., aviso, inactividad, caducidad, reservado
/etc/group4 campos: nombre:x:GID:miembros (no lista a quien lo tiene como primario)
/etc/gshadowcontraseñas de grupo y administradores
/etc/login.defsvalores por defecto (rangos UID/GID…)
/etc/skelplantilla que se copia al nuevo home (.bashrc, .profile, .bash_logout)

.bashrc: se lee en cada terminal nuevo (alias, prompt). .profile/.bash_profile: solo al iniciar sesión (PATH…). .bash_logout: al salir.

6. Modificar cuentas

OrdenQué hace
passwd usuariocambia la contraseña (root no necesita la actual)
passwd -l / -u / -d / -Sbloquear / desbloquear / quitar contraseña / ver estado (P, L, NP)
usermod -d dir [-m]cambia el home (con -m mueve los archivos)
usermod -G g1,g2 [-a]sustituye los grupos secundarios; con -a los añade
usermod -l / -L / -U / -urenombrar / bloquear / desbloquear / cambiar UID
chage -m / -Mmínimo / máximo de días entre cambios de contraseña
chage -l / -E / -W / -Iver datos / caducidad de cuenta / días de aviso / inactividad

7. Eliminar usuarios

userdel usuario borra la cuenta; -r borra también su home y su correo; -f fuerza. Si olvidaste -r, busca sus archivos por UID: find / -uid N. Copia previa: find / -xdev -user user1 -type f -print0 | tar --null -czf /root/user1.tar.gz -T -.

8. su y sudo

OrdenQué hace
su usuariocambia de usuario pero conserva tu directorio actual
su - usuarioentra como ese usuario con su entorno y su home
sudo ordenejecuta una orden como root usando tu contraseña (grupo sudo, fichero /etc/sudoers; recuerda la clave ~15 min)
sudo -i / sudo -sshell de root (prompt con #); salir con exit

En Ubuntu root está bloqueado por defecto (* en shadow). Se activa con sudo passwd root y se bloquea con sudo passwd -dl root.

9. Configurar grupos

OrdenQué hace
groupadd [-g GID] [-r] gcrear grupo (-r = de sistema)
groupmod -n nuevo g / -g GIDrenombrar / cambiar GID
gpasswd -a u g / -d u gañadir / quitar un usuario sin tocar los demás grupos (preferible)
gpasswd -A / -Msustituir administradores / miembros del grupo
groupdel gborrar (no deja si es primario de alguien)
groups u, id uver los grupos de un usuario

10. Ejemplo (Ada Lovelace)

  1. sudo useradd -c "Ada Lovelace" -s /bin/bash -m alovelace
  2. sudo passwd alovelace
  3. sudo groupadd babbage
  4. sudo usermod -a -G babbage alovelace
  5. sudo chage -E 2026-12-15 -m 10 -M 20 alovelace y sudo chage -l alovelace
